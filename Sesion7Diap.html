🔤 ¿QUÉ ES EL LENGUAJE M?

🤖📝✨

💡 M Language: El motor de Power Query

  • Funcional: Cada paso es una función pura
  • Inmutable: No modifica datos originales
  • Poderoso: Transformaciones complejas simples
  • Legible: Código que se explica solo

🎮 Dato Curioso:

"M" viene de "Mashup" - porque "mezcla" datos de múltiples fuentes de manera elegante. ¡Es como ser un DJ de datos! 🎧

🔬 ANATOMÍA DE UNA FÓRMULA M

🧬 Estructura Básica

let // 1. VARIABLES (let-in block) Fuente = Excel.Workbook(File.Contents("C:\mi_archivo.xlsx")), Hoja = Fuente{[Name="Ventas"]}[Data], // 2. TRANSFORMACIONES TiposCorregidos = Table.TransformColumnTypes(Hoja, {{"Fecha", type date}}), ColumnaNueva = Table.AddColumn(TiposCorregidos, "Beneficio", each [Ventas] - [Costos]), // 3. RESULTADO FINAL ResultadoFinal = ColumnaNueva in ResultadoFinal
📝

LET-IN BLOCK

Organiza tu código como un chef organiza ingredientes

🔄

EACH KEYWORD

Magia que se aplica a cada fila automáticamente

⚡ FÓRMULAS M ESENCIALES

➕

Table.AddColumn

Crea nuevas columnas con lógica personalizada

Table.AddColumn(tabla, "Nueva", each [Col1] + [Col2])
🔗

Text.Combine

Une textos como un hechizo de concatenación

Text.Combine({[Nombre], [Apellido]}, " ")
📅

Date.AddDays

Viaja en el tiempo sumando/restando días

Date.AddDays([FechaVenta], 30)
🎯

Number.Round

Redondea números con precisión matemática

Number.Round([Precio] * 1.16, 2)

🎪 EJEMPLOS DIVERTIDOS

🕵️ El Detective de Correos

Misión: Extraer el dominio de emails

// De "juan@empresa.com" → "empresa.com" Table.AddColumn(Source, "Dominio", each Text.AfterDelimiter([Email], "@"))

👨‍🍳 El Chef de Categorías

Misión: Clasificar ventas por tamaño

// Clasifica ventas: Pequeña, Mediana, Grande Table.AddColumn(Source, "Categoria", each if [Ventas] < 1000 then "Pequeña" else if [Ventas] < 5000 then "Mediana" else "Grande")

⏰ El Viajero del Tiempo

Misión: Calcular edad en días

// ¿Cuántos días has vivido? Table.AddColumn(Source, "DíasVividos", each Duration.Days(DateTime.LocalNow() - [FechaNacimiento]))

🤔 CONDICIONALES EN M

🧠 IF-THEN-ELSE: La lógica del universo

// Estructura básica if [condición] then [valor_si_verdadero] else [valor_si_falso] // Ejemplo real: Clasificar estudiantes Table.AddColumn(Source, "Estatus", each if [Calificacion] >= 90 then "Excelente" else if [Calificacion] >= 80 then "Bueno" else if [Calificacion] >= 70 then "Regular" else "Necesita mejorar")

📅 MAESTRÍA EN FECHAS

🎯 Extraer Componentes

⚡ Cálculos Temporales

// Diferencia entre fechas Duration.Days([FechaFin] - [FechaInicio]) // Agregar tiempo Date.AddMonths([Fecha], 3)

💼 Lógica de Negocio

// Es fin de semana? Date.DayOfWeek([Fecha]) >= 5 // Trimestre "Q" & Text.From(Date.QuarterOfYear([Fecha]))

🎭 Teatro de Fechas:

En Power BI, las fechas son números disfrazados. El 1 de enero de 1900 = 1. ¡Como contar días desde el año 1900! 📊

✂️ CIRUGÍA DE TEXTO

🧼 El Limpiador Supremo

// Limpia texto como un profesional Table.TransformColumns(Source, {{"Nombre", each Text.Trim(Text.Proper(Text.Clean(_)))}}) // Resultado: " jUaN péREz " → "Juan Pérez"

🔍 El Extractor de Secretos

// Extrae códigos de productos: "PROD-ABC-123" Table.AddColumn(Source, "Categoria", each Text.BetweenDelimiters([Codigo], "-", "-")) // Resultado: "PROD-ABC-123" → "ABC"

🎭 El Maestro del Disfraz

// Reemplaza múltiples valores en una sola línea Text.Replace(Text.Replace([Texto], "viejo1", "nuevo1"), "viejo2", "nuevo2") // O mejor aún, con una función personalizada!

// Función para calcular descuento progresivo (cantidad as number) as number => if cantidad >= 10000 then cantidad * 0.15 else if cantidad >= 5000 then cantidad * 0.10 else if cantidad >= 1000 then cantidad * 0.05 else 0 // Uso: CalcularDescuento(8500) = 850

📧 Función: Validador de Emails

Crea una función que valide si un email es correcto

(email as text) as logical => Text.Contains(email, "@") and Text.Contains(email, ".") and Text.Length(email) > 5

🎯 Función: Calculadora de Score

Combina múltiples factores en un score único

(ventas as number, antiguedad as number, region as text) as number => let BaseScore = ventas / 1000, BonusAntiguedad = antiguedad * 5, BonusRegion = if region = "Premium" then 50 else 0 in BaseScore + BonusAntiguedad + BonusRegion

⚡ PODER DAX: MEDIDAS DINÁMICAS

📊⚡🎯
🧮

DAX BÁSICO

// Ventas totales Total Ventas = SUM(Ventas[Monto]) // Promedio con filtros Promedio Ventas = AVERAGE(Ventas[Monto])
📅

INTELIGENCIA TEMPORAL

// Ventas año anterior Ventas Año Anterior = CALCULATE([Total Ventas], SAMEPERIODLASTYEAR(Calendario[Fecha])) // Crecimiento % Crecimiento % = DIVIDE([Total Ventas] - [Ventas Año Anterior], [Ventas Año Anterior], 0)
🚀

DAX AVANZADO

// Top 3 productos por región Top 3 Productos = CALCULATE([Total Ventas], TOPN(3, ALLSELECTED(Productos[Nombre]), [Total Ventas]))

🎨 PATTERNS DAX PROFESIONALES

🏆 Pattern: ABC Analysis

ABC Classification = VAR VentasProducto = [Total Ventas] VAR TotalGeneral = CALCULATE([Total Ventas], ALL(Productos)) VAR PorcentajeAcumulado = CALCULATE( DIVIDE( SUMX( FILTER( ALL(Productos), [Total Ventas] >= VentasProducto ), [Total Ventas] ), TotalGeneral ) ) RETURN IF(PorcentajeAcumulado <= 0.8, "A", IF(PorcentajeAcumulado <= 0.95, "B", "C"))

🏎️ OPTIMIZACIÓN DE MODELOS

🔗

RELACIONES INTELIGENTES

  • Estrella > Copo de nieve
  • Bidireccional solo si necesario
  • Tabla de fechas siempre
  • Claves únicas garantizadas
⚡

PERFORMANCE

  • Columnas calculadas vs Medidas
  • SUMMARIZE vs ADDCOLUMNS
  • Variables en DAX
  • Filtros tempranos
💾

MEMORIA

  • Cardinalidad baja en dimensiones
  • Tipos de datos correctos
  • Eliminar columnas innecesarias
  • Compresión automática

🧠 Neurona de Datos:

Un modelo bien optimizado puede ser 10x más rápido. ¡Es la diferencia entre esperar 10 segundos o 100 segundos por un reporte! ⚡
